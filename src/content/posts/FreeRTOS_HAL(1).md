## 一．什么是FREERTOS

RTOS的最大特征就是“实时性”。所有实时操作系统中都要包含一个实时任务调度器，这个任务调度器与其它操作系统的最大不同是强调严格按照优先级来分配CPU时间。

FREERTOS（FREE Real-Time Operating System，免费实时操作系统） 是一种专为处理具有严格时间约束任务而设计的操作系统。它的核心价值不在于处理速度有多快，而在于响应的可预测性和确定性。

FreeRTOS 操作系统是一个功能强大的RTOS 操作系统，并且能够根据需求进行功能裁剪，以满足各种环境的要求、高效、开源、免费。

### 1.裸机与RTOS的执行区别

举个栗子：打游戏和回信息两个事件在裸机和RTOS中运行分别是什么样子的？

#### 裸机：
```bash
Whlie(1)
{
    打游戏（）;
    回信息（）;
}
```

程序是有序性的，先打完游戏才会去回信息。

#### RTOS：
```bash
xTaskCrete(打游戏);
xTaskCrete(回信息);

void 游戏(void const * argument)
{
for(;;)
{
打游戏();
}
}
void 信息(void const * argument)
{
for(;;)
{
回信息();
}
}
```

！[每个任务之间隔着个时间片](./FreeRTOS-image(1).png)

两个任务之间间隔一个很小的时间片，打游戏间隔一个时间片回信息，回信息间隔一个时间片打游戏，其实按照时间片轮转的方式进行调度，由于时间片非常小，在宏观看来，这两个任务像是同时运行的。


## 2.任务的概念

任务是一个独立的函数，函数主体无限循环且不能返回。
在裸机系统中，系统的主体就是main函数里面顺序执行的无限循环，这个无限循环里面 CPU 按照顺序完成各种事情。在多任务系统中，我们根据功能的不同，把整个系统分割成一个个独立的且无法返回的函数，这个函数我们称为任务。


## 3.任务的栈

在多任务系统中，每个任务都是独立的，互不干扰的，所以要为每个任务都分配独立的栈空间，这个栈空间通常是一个预先定义好的全局数组， 也可以是动态分配的一段内存空间，但它们都存在于 RAM 中。在多任务系统中，有多少个任务就需要定义多少个任务栈。


## 4.RTOS的特点

分而治之： 实现功能划分为多个任务
延时函数： 任务调度
抢占式：   高优先级任务抢占低优先级任务
任务堆栈： 每个任务都有自己的栈空间

注意1：中断可以打断任意任务
注意2：任务可以是同等优先级


## 5.任务调度简介

FREERTOS一共支持三种任务调度
抢占式调度：主要针对优先级不同的任务，每个任务都有一个优先级，优先级高的任务可以抢占优先级较低的任务。
时间片调度：主要针对优先级相同的任务，当多个任务的优先级相同时，任务调度器会在每一个时钟节拍到的时候切换任务。
协程式调度：当前执行任务将会一直运行，同时高优先级的任务不会抢占低优先级任务。FREERTOS现在虽然还支持，但是官方已经表示不再更新协程式调度。


## 6.任务状态

运行态：正在执行的任务，该任务就处于运行态，注意在STM32中，同一时间仅一个任务处于运行态。
就绪态：如果该任务已经能够被执行，但当前还未被执行，那么该任务处于就绪态。
阻塞态：如果一个任务因延时或等待外部事件发生，那么这个任务就处于阻塞态。
挂起态：类似暂停，调用函数xTaskSuspend()进入挂起态，需要调用解挂函数xTaskResume()才可以进入就绪态。

## 二．Cubemx参数认识

### 1.RTOS版本选择

！[RTOS版本的选择](./FreeRTOS-image(2).png)

V1和V2版本主要的区别在于，V2兼容支持的硬件更多，但内存耗费也更多；
对于常见的Cortex-M3、M4、M7芯片，选择V1即可。

### 2.配置内核参数

！[内核参数](./FreeRTOS-image(3).png)

核心监控区（随程序运行实时变化）
Task and Quenes：       任务与消息队列的创建。
Timers and Semaphores： 定时器和信号量的创建。
Mutexes：               互斥量的创建。
FreeRTOS Heap Usage：   用于查看堆使用情况。
Events：                查看事件标志组（Event Groups）的创建和当前状态。

静态参数区（只读信息，不随程序变化）
config parameters：     内核参数设置，用户根据自己的实际应用来裁剪定制FreeRTOS内核。
Include parameters：    FreeRTOS部分函数的使能。
User Constants：        相关宏的定义，可以自建一些常量在工程中使用。
Advanced settings ：    配置调试器自身的行为。
